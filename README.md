# تجربة TCP وTLS مع الرسائل وبصمة الملفات

مشروع تعليمي يوضح الفرق بين اتصال TCP عادي واتصال TLS، مع إرسال رسائل وحساب بصمة SHA-256 لملف على العميل والخادم. يحتاج Python 3.10 أو أحدث.

## الميزات

- خادم واحد يستقبل اتصالات TCP عادية واتصالات TLS على منفذين منفصلين.
- TLS يتحقق من شهادة الخادم واسم المضيف باستخدام شهادة محلية ذاتية التوقيع.
- إرسال رسائل نصية بين العميل والخادم.
- إرسال ملف حتى 50 MiB ليحسب الخادم بصمة SHA-256 ويقارنها العميل بالبصمة التي حسبها أثناء الإرسال. لا يحفظ الخادم الملف.
- تأطير رسائل JSON بطول مسبق، وقراءة متدفقة للبيانات لتجنب افتراض أن استدعاء `recv()` واحد يعيد الرسالة كاملة.

## التشغيل على Windows

من مجلد المشروع افتح نافذتي PowerShell. في الأولى أنشئ البيئة وثبّت المتطلبات ثم شغّل الخادم:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

ينشئ الخادم `server.crt` و`server.key` محلياً عند أول تشغيل. في النافذة الثانية شغّل العميل:

```powershell
.\.venv\Scripts\python.exe client.py
```

اختر TLS أو TCP عادي، ثم أرسل رسالة أو اختر ملفاً لحساب البصمة. الخادم مربوط على `127.0.0.1` للعمل محلياً على نفس الجهاز.

## الملفات

- `client.py`: واجهة العميل واختيار نمط الاتصال والرسالة أو الملف.
- `server.py`: خادما TCP وTLS ومعالجة الطلبات.
- `protocol.py`: تأطير رسائل JSON وقراءة عدد محدد من البايتات.
- `requirements.txt`: مكتبة توليد الشهادة المحلية.

## نطاق التجربة

اتصال TCP العادي غير مشفر. في نمط TLS يثق العميل بالشهادة الذاتية التوقيع الموجودة بجانب الكود ويتحقق من الاسم `localhost`؛ هذا مناسب لتجربة محلية فقط. لا تستخدم الشهادة أو الخادم كإعداد إنتاجي. فحص SHA-256 هنا يبيّن إن كانت البايتات التي وصلت للخادم تطابق ما أرسله العميل، ولا يمثل بديلاً عن مصادقة TLS أو تخزين آمن للملفات.

لا يتضمن هذا الإصدار طبقة AES منفصلة فوق TLS. محاولة AES القديمة كانت بلا خادم مطابق وتستخدم نمط CTR من دون مصادقة للرسائل. الملفات الأصلية محفوظة كما هي، وهذه نسخة مصححة ومستقلة.

## أرشيف النسخة الأصلية

يحتوي مجلد `OldVertion` على محاولات أولية محفوظة لأغراض التعلّم فقط، وليس كنسخة جاهزة أو آمنة للتشغيل. بعض الملفات القديمة لا تتحقق من شهادة TLS، ومحاولة AES القديمة تستخدم CTR من دون مصادقة، كما أن بعض المسارات لا تملك خادمًا مطابقًا أو تحتوي أخطاء برمجية. النسخة التعليمية الحالية هي الملفات الموجودة في المجلد الرئيسي.
